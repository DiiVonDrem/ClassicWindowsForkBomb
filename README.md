Files or codes such as these, commonly named 'fork bombs' (and sometimes referred to as 'rabbit' or 'hydra' viruses), are one of the easiest DoS (Denial of Service) attacks.

The base of the code is always the same: a process that duplicates itself almost the same instant it starts.

This leads to the system drastically slowing down until all memory is full, leading to a crash.
